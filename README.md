# Скорость скачивания

Консольный скрипт один раз открывает соединение к указанному адресу, затем делает 10 запросов **по очереди**, дожидается полного тела каждого ответа и печатает среднее время, суммарный объём и скорость скачивания.

## Запуск

Нужен Python 3.10+.

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python speed.py "https://speed.cloudflare.com/__down?bytes=10000000"
```

На macOS и Linux активация окружения: `source .venv/bin/activate`.

Адрес передаётся одним аргументом. Подойдёт любой `http` или `https` URL; для внятной цифры лучше файл от нескольких мегабайт — на маленьком ответе почти всё время уходит на установку соединения.

## Единицы

Скорость печатается в **Мбит/с** (мегабит в секунду).

- 1 байт = 8 бит
- 1 Мбит = 1 000 000 бит
- скорость = (сумма байт всех ответов × 8) / (сумма секунд всех запросов) / 1 000 000

Время одного запроса — от старта запроса до последнего байта тела. В объём входят байты тела так, как их отдал сервер, без распаковки gzip. Запросы идут последовательно, одно за другим.

Перед замером скрипт отправляет один `HEAD` на тот же адрес и печатает его время строкой `warmup`. Этот запрос в среднее время, объём и скорость не входит: он нужен, чтобы открыть соединение. Дальше десять `GET` идут по нему, если сервер держит keep-alive.
